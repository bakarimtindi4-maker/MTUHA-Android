# MTUHA Android App — mradi wa Android Studio

Mradi huu umeweka faili za PWA ya MTUHA ndani ya Android app na kuwezesha JavaScript, DOM storage, ruhusa ya GPS na kuchagua/pakia picha kupitia fomu za HTML.

## Kutengeneza APK
1. Sakinisha Android Studio kwenye kompyuta.
2. Fungua Android Studio > **Open** na uchague folda hii ya `MTUHA_Android` baada ya ku-extract ZIP.
3. Ruhusu Gradle Sync ikamilike na usakinishe Android SDK Platform 35 ikiombwa.
4. Chagua **Build > Build APK(s)**.
5. APK ya majaribio itapatikana ndani ya `app/build/outputs/apk/debug/`.

## Muhimu
- Hii ni Android Studio project source, si APK iliyokwisha compile.
- Jaribu kwenye simu halisi kabla ya matumizi rasmi: uhifadhi wa data, picha/kamera, GPS, na ripoti lazima vikaguliwe.
- Hifadhi ya taarifa ya ndani hutegemea namna `index.html` ilivyoandikwa. Hii haiongezi moja kwa moja seva ya mtandaoni wala usawazishaji kati ya simu.
